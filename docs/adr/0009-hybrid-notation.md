# ADR 0009: 本文の記法は「Cosense のリンク ＋ Markdown の装飾」の併用

- 日付：2026-10-15
- 状態：採用（ユーザー決定）
- 変更する設計：§6.1（Cosense 風の記法だけ、Markdown を前提にしない）

## 決定

形式名は `link-text-v1` のまま変えない。保存される本文はプレーンテキストで、パーサーは `packages/content/src/parse.ts` にある。

| 種類 | 記法 | 由来 |
|---|---|---|
| ページへのリンク | `[ページ名]`（未作成のページでもよい） | Cosense |
| タグ | `#タグ`（行頭か空白の直後のときだけ。`C#` はタグにしない） | Cosense |
| 外部リンク | `[ラベル](https://…)`、`[https://… ラベル]`、`[ラベル https://…]`、本文中にそのまま書いた URL | Markdown と Cosense |
| リンクカード | URL だけを書いた行（ADR 0010） | 独自 |
| 見出し | `#`〜`######` の後に空白（行頭、インデントなしのときだけ） | Markdown |
| 箇条書き | `- ` `* ` `+ ` `1. `、行頭の空白の数がそのまま階層（Cosense と同じ） | 両方 |
| 引用・区切り線 | `> 引用`、`---` | Markdown |
| 太字・斜体・取り消し線 | `**太字**`、`*斜体*` / `_斜体_`、`~~取消~~` | Markdown |
| Cosense の装飾 | `[* 太字]`、`[** 大きい太字]`、`[/ 斜体]`、`[- 取消]`、`[_ 下線]` | Cosense |
| コード | `` `インライン` ``、```` ``` ```` で囲むブロック、`code:ファイル名` ＋ その下のインデント行 | 両方 |
| 画像 | `[asset:UUID]`（表示は Phase 4） | 独自 |
| 数式 | `[$ x^2]`（今は等幅の文字で表示。描画は Phase 10 で検討） | Cosense |
| エスケープ | `\[`、`\*`、`\#` など | Markdown |

## 方針

- **何も消さない**：解釈できない記法は文字のまま表示する。
- **コードの中は解析しない**：コードの中のリンク・タグ・装飾は解釈しない（保存されるリンク一覧にも入れない）。
- **パーサーの計算量**：入力の長さに比例するように書き、正規表現のバックトラッキングで遅くならないようにした。病的な 45,000 文字の入力でもテストで 500ms 以内に収まることを確認している。
- **Markdown との違い**：Markdown 固有の文法（表、脚注、HTML、`[[...]]` 形式のリンク）は採用しない。HTML は常にエスケープして文字として表示する。

## 表示と編集（同じ CSS を使う）

- **閲覧画面**：`lib/content/Rendered.svelte`（SSR）で描画する。
- **エディタ**：`lib/editor/live.ts`。
  - フォーカスしていないときと、カーソルのない行は閲覧画面と同じ見た目にする。記号は replace decoration で隠し、カードは widget で表示する。
  - カーソルのある行は生のテキストを表示する（記号は薄く表示）。
- **共通の CSS**：`lib/styles/content.css`。
- **操作**
  - カーソルのない行のリンクはクリックで移動する。カーソルのある行では Cmd / Ctrl ＋ クリックで移動する。
  - `[` と `#` でタイトルを補完する。IME で変換している間は補完しない。
  - Enter で箇条書きを続け、空の項目で Enter を押すと箇条書きを終える。
  - Tab で 1 段インデントする（空白 1 つ）。

## 影響

- Cosense のページ（約 2,000）は、基本的に書き換えなしで読める。表（`table:`）、アイコン（`[name.icon]`）、`[$ ]` の数式の描画は、Phase 10 で実データを棚卸しして対応を決める（`docs/compatibility.md`）。
- `[ラベル](url)` が使えるようになったため、`[ラベル]` の直後に `(` と URL が続く書き方は外部リンクとして解釈される。
