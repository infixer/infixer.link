# ADR 0010: 外部リンクのカード表示（Cosense にはない機能）

- 日付：2026-10-15
- 状態：採用（ユーザーの要望）。カードの画像は Phase 4 で対応

## 決定

- **カードになる行**：URL だけを書いた行（インデントや箇条書きの中も含む）をリンクカードとして表示する。文中の URL と `[ラベル](URL)` は、普通のリンクのまま表示する。
- **URL の貼り付け**（2026-10-15 追加、ユーザーの要望）：URL だけを貼り付けると、独立した行として挿入し、カーソルを次の行に移す。リンク先の情報が取れしだい、その場でカードになる。`[` や `(` の直後、`[ラベル](` の中に貼った場合は、文字のまま入れる。
- **表示する内容**：タイトル、説明（2 行まで）、サイト名またはドメイン。OGP がない、または取得できなかった場合は普通のリンクとして表示する。
- **メタデータの取得は本人の操作から**
  - エディタが新しいカード行を見つけたときに `POST /api/owner/v1/link-previews` を呼び、サーバーが取得して `link_previews` テーブルにキャッシュする（成功したものは 7 日、失敗したものは 1 日で再取得の対象）。
  - **公開ページの表示では外部へアクセスしない**（D1 のキャッシュを読むだけ）。閲覧者のアクセスをきっかけに外部へ送信が起きることはない。
- **安全策**（`src/lib/server/previews.ts`）
  - 取得先は http / https だけ。ポートは既定のものだけ。URL に資格情報（ユーザー名・パスワード）が入っていれば拒否する。
  - localhost、RFC1918 などのプライベートアドレス、リンクローカル、`.local` / `.internal`、ドットを含まないホスト名は拒否する。
  - リダイレクトは手動で最大 3 回までたどり、毎回同じ検査をする。
  - タイムアウトは 5 秒。本文は先頭 512KiB だけ読む。HTML 以外は解析しない。
  - 取り出すのは `<head>` の OGP / Twitter / `<title>` / description だけで、文字数の上限を決めて整形する。描画は Svelte がエスケープする。
  - ローカル開発と E2E だけ `LINK_PREVIEW_ALLOW_LOCAL=true` で localhost を許可する（staging / production では設定しない）。
- **画像**：`og:image` の URL は保存するが、**表示しない**。外部の画像を直接表示すると、閲覧者の IP が外部サイトに伝わり、CSP の `img-src` も緩める必要がある。Phase 4 で R2 に取り込んでから表示する。
- 自サイトのページにも `og:title` / `og:description` / `og:site_name` を出すようにした（他のサイトでのカード表示と E2E 用）。

## 代案

- **外部の画像を直接表示する**：プライバシーと CSP の理由で不採用。
- **閲覧時に取得する**：閲覧者のアクセスが外部へのリクエストを生み、遅延と悪用の原因になるため不採用。
- **HTMLRewriter で抽出する**：workerd 以外（`vite dev`）でも同じ挙動にするため、`<head>` に限って上限付きの正規表現で抽出する方式を採った。

## 未検証

- 実際の外部サイト（staging から）での取得成功率。Bot 判定でブロックされるサイトはカードにならない。
