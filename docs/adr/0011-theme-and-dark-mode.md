# ADR 0011: 見た目を infixer.net に合わせ、ダークモードに対応する

- 日付：2026-10-15
- 状態：採用（ユーザーの要望。参考：https://infixer.net/ 、リポジトリ infixer/ryokatsuse_web）

## 決定

- **配色トークン**（`src/lib/styles/base.css`）

  | 用途 | ライト | ダーク |
  |---|---|---|
  | 背景 | `oklch(100% 0 0)` | `oklch(26.9% 0 0)` |
  | 文字 | `oklch(28% 0 0)` | `oklch(98.5% 0.002 247.839)` |
  | 枠線 | gray-200 | gray-700 |

  - ヘッダーは両モードとも暗い帯に白い文字（infixer.net と同じ）。
  - リンクは文字色のまま下線を付け、ホバーで下線を消す。未作成のページへのリンクは薄い色の点線にする。
  - インラインコードは暗い背景に白い文字。コードブロックは github-dark 系（`#24292e`）。
  - 引用は左の線と薄い背景、斜体。リンクカードは角丸の枠で、ホバーすると影が付く。
- **テーマの切り替え**（`src/lib/ThemeSwitch.svelte`）
  - ライト / ダーク / システム設定の 3 状態。選択中のボタンをもう一度押すとシステム設定に戻る。保存先は `localStorage.theme`。
  - 最初の描画より前に、`app.html` のインラインスクリプト（nonce 付き）が `html.light` か `html.dark` を付けるので、画面がちらつかない。
  - JavaScript が無効なときは `prefers-color-scheme` に従う。
  - システム設定に従っているあいだは、OS の設定変更にも追従する。
- **ヘッダー**：上部に固定し、下にスクロールすると隠れ、上にスクロールすると戻る。フォーカスが中にあるあいだは隠さない。
- **フォント**：infixer.net は Noto Sans JP の Web フォントを使うが、設計 §4.2「Web フォントを初期ロードしない」に従い、システムフォントのままにする（`Noto Sans JP` を含むフォント指定）。

## 同時に直した不具合

1. **エディタのカーソルが見えない、または行の外に描かれる**
   - 原因：SvelteKit は CSP の nonce を `script-src` にしか付けない。そのため、CodeMirror が `<style nonce>` で差し込む基本スタイルがブロックされ、カーソルと選択範囲のレイヤーが位置を失って本文の下に描かれていた。カーソル自体も黒い 1.2px で、ダークモードではほぼ見えなかった。
   - 対策
     - `hooks.server.ts` で、同じ nonce を `style-src` にも追加する。
     - カーソルは `--color-caret`（ライトは濃い色、ダークは白）の 2px、選択範囲は `--color-selection` にする。
   - E2E で、カーソルが文字の終わりの位置にあること、色、幅、エディタのページで CSP エラーが出ていないことを検査する。
2. **SvelteKit のページ遷移の読み上げ要素がインラインの `style` 属性を使っていて CSP でブロックされていた**（Phase 1 から）
   - そのままだと、ページを移動したときにタイトルの文字が画面左上に見えてしまう。
   - 対策：その属性だけを `'unsafe-hashes'` ＋ sha256 で許可し、同じ非表示のスタイルを CSS にも書いた。
3. **行に margin を使っていた**：見出しの行の margin が CodeMirror の位置計算とずれるので、padding に変えた。行には margin を使わない（`content.css` の先頭にこの規則をコメントで残した）。
