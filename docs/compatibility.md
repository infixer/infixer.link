# Cosense 互換性（設計 §6.2）

実データの棚卸しは Phase 10 で行う。ここには、現在の対応状況を記録する。記法の方針は ADR 0009。

| 記法 | 状態 | 備考 |
|---|---|---|
| `[ページ名]` リンク、未作成リンク | 対応（Phase 3） | 未作成のページは `/t/{name}` に移動し、本人だけが作成できる |
| `#タグ` | 対応 | |
| 行頭スペースのインデント（箇条書き） | 対応 | 空白 1 つが 1 段 |
| `[* 太字]` `[** 大]` `[/ 斜体]` `[- 取消]` `[_ 下線]` | 対応 | 記号を組み合わせた装飾（`[*/ x]` など）は、`*` を優先して太字にする |
| `[https://… ラベル]` / `[ラベル https://…]` | 対応 | |
| URL だけの行 | カード表示（Cosense にはない） | ADR 0010 |
| YouTube の URL だけの行 | 埋め込みプレイヤー | サムネイル＋再生ボタン。押すと youtube-nocookie.com のプレイヤーを読み込む（ADR 0014） |
| ページ一覧 | カード表示 | 最初の画像・カード・動画のサムネイル。なければ最初の数行（ADR 0014） |
| `` `code` ``、`code:ファイル名` | 対応 | シンタックスハイライトは未対応 |
| `[$ 数式]` | 文字として表示 | TeX の描画は未対応 |
| `table:名前` | 未対応（文字のまま表示） | Phase 10 で利用状況を見て決める |
| `[name.icon]` アイコン | 未対応（リンクとして表示） | Phase 10 |
| `[https://….png]` 外部画像 | 外部リンクとして表示 | Phase 10 で R2 に取り込み、`[asset:…]` に置き換える（ADR 0012 の仕組みを使う） |
| Gyazo の URL | 外部リンク | Phase 10 で R2 に移行する |
| 引用 `> ` | 対応 | |
| UserScript / UserCSS | v1 の対象外 | |

## 検索（Phase 5、ADR 0013）

| 項目 | 状態 | 備考 |
|---|---|---|
| 1〜2 文字の日本語 | 対応 | LIKE で全ページを読む（10,000 ページで p95 40ms、ローカル） |
| 3 文字以上・長い語 | 対応 | FTS5 trigram |
| 英数字の混在、大文字・小文字 | 対応 | 大文字・小文字は区別しない。全角と半角の英数字は別の文字 |
| 複数の語 | AND | スペース（全角を含む）で区切る。Cosense の `-除外` や OR は未対応 |
| 名前・別名 | 完全一致と前方一致を優先 | 古い名前は完全一致・前方一致でだけ見つかる |
